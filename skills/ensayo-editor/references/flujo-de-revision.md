# Flujo de revisión

## Contenido

1. Delimitar y leer
2. Mapear la voz
3. Revisar por capas
4. Seleccionar hallazgos
5. Ejecutar según modo
6. Controlar la sobrecorrección
7. Entregar y trabajar con archivos

## 1. Delimitar

Registrar mentalmente:

- modo o combinación de modos;
- alcance: fragmento, sección o ensayo completo;
- salida pedida: informe, comparaciones, diff o versión limpia;
- restricciones explícitas;
- disponibilidad de muestras previas autorizadas.

No exigir contexto biográfico para empezar. Si no se especifica modo, usar diagnóstico.

## 2. Leer sin corregir

Hacer una primera lectura para reconstruir:

- qué intenta decir el texto;
- desde dónde habla;
- qué tensión o pregunta lo mueve;
- qué registro domina;
- dónde cambia el ritmo;
- qué pasajes parecen nucleares.

No editar durante esta lectura. Evitar que el primer tropiezo dicte una reescritura global.

## 3. Mapear la voz local

Comparar el perfil general con la evidencia del texto actual:

- persona y distancia;
- vocabulario;
- longitud y cadencia;
- grado de certeza;
- relación entre escena y reflexión;
- humor, duda, contradicción y aspereza.

Dar prioridad al texto actual. Identificar al menos un pasaje que convenga preservar si existe; no inventar elogios si el texto no ofrece evidencia.

## 4. Revisar por capas

### Capa A: contenido atribuido

Marcar tesis, opiniones, experiencias o interpretaciones que parezcan aparecer de golpe. Tratar como crítico cualquier contenido posiblemente agregado por una IA o por una revisión previa.

### Capa B: argumento

Reconstruir:

1. tesis explícita o pregunta central;
2. razones ofrecidas;
3. evidencia o ejemplos;
4. inferencias;
5. alcance de la conclusión.

Marcar `[REQUIERE FUENTE]` donde corresponda. Diferenciar contradicción productiva de contradicción invalidante.

### Capa C: voz artificial

Aplicar las familias de [patrones-ia-espanol.md](patrones-ia-espanol.md). Contar tendencias, no solo palabras. Comparar el fragmento sospechoso con el registro circundante.

### Capa D: frase

Revisar ortografía, puntuación, sintaxis, concordancia, referentes, repetición y conectores. No usar esta capa como excusa para uniformar.

## 5. Seleccionar hallazgos

Ordenar por:

1. contenido inventado o postura alterada;
2. problema que compromete tesis o comprensión;
3. patrón artificial acumulado;
4. error local;
5. opción estilística.

No llenar una cuota de problemas. Agrupar repeticiones de un mismo patrón y usar ejemplos representativos.

## 6. Ejecutar según modo

### Diagnóstico

- Citar fragmentos mínimos.
- Explicar efecto y gravedad.
- No reescribir el ensayo.
- Ofrecer una dirección de cambio solo si aclara el diagnóstico.

### Corrección mínima

- Cambiar la menor unidad posible.
- Entregar cambios localizados o diff.
- Explicar decisiones relevantes; poder agrupar correcciones mecánicas.
- Dejar intacta una rareza cuando su función sea probable.

### Auditoría de voz artificial

- Informar patrones, frecuencia aproximada y acumulación.
- Señalar pasajes que conservan voz para crear contraste.
- No atribuir autoría con certeza ni hablar de evasión de detectores.

### Revisión argumentativa

- Separar observaciones de contenido y estilo.
- Mapear tesis, razones, evidencia e inferencias.
- Usar `[REQUIERE FUENTE]` sin inventar fuentes.
- No corregir el estilo salvo que impida evaluar el argumento.

### Propuesta comparada

Usar original, problema, propuesta, motivo, intervención y confianza para cada cambio relevante. Incluir “mantener sin cambios” cuando demuestre calibración.

### Versión limpia

- Confirmar que el pedido es explícito.
- Aplicar solo cambios justificados o aprobados.
- Comparar contra el original para detectar ideas nuevas.
- Si se trata de un archivo, preservar original y producir copia o diff.

## 7. Control contra sobrecorrección

Antes de entregar, comprobar:

- ¿se agregó una idea, emoción, experiencia o conclusión?
- ¿aumentó el grado de certeza?
- ¿se volvió más académico o más coloquial sin motivo?
- ¿se uniformaron las frases?
- ¿desapareció una contradicción fértil?
- ¿se explicó una ironía?
- ¿se añadió rioplatense decorativo?
- ¿se sustituyó un párrafo entero por comodidad?
- ¿se confundió un pasaje logrado con voz artificial?

Revertir cualquier cambio que falle este control.

## 8. Entregar

Usar el formato base del `SKILL.md`, adaptado al modo. Priorizar pocos hallazgos demostrables. Terminar indicando:

- qué corregir primero;
- qué dejar intacto;
- qué depende de una decisión del autor;
- qué requiere fuente o verificación.

## 9. Trabajar con archivos

Si el usuario autorizó edición:

1. resolver las rutas exactas;
2. leer instrucciones locales;
3. verificar que no sean diario u original único protegido;
4. crear copia o diff;
5. aplicar solo el alcance pedido;
6. revisar el diff por fidelidad semántica;
7. enumerar archivos modificados.
