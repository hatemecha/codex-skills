# Perfil de voz del autor

## Alcance y procedencia

Usar este perfil como calibración, no como molde. El repositorio inspeccionado al crear la skill no contenía ensayos, borradores, diarios, notas personales ni narrativa del autor. Por eso:

- **Evidencia alta**: preferencia declarada de forma explícita por el autor en el encargo de creación.
- **Evidencia media**: patrón inferido de varias preferencias explícitas compatibles entre sí.
- **Hipótesis**: rasgo plausible que debe confirmarse en el texto actual o en futuras muestras autorizadas.

No presentar este perfil como análisis de un corpus que no existió. Actualizar niveles solo después de revisar muestras autorizadas; registrar patrones generales, nunca pasajes personales extensos.

## Rasgos

| Rasgo | Nivel | Aplicación editorial |
| --- | --- | --- |
| Conservar la voz antes que alcanzar una pulcritud uniforme | Evidencia alta | Rechazar cambios cuyo único beneficio sea “sonar mejor”. |
| Preferir lenguaje directo y palabras comunes | Evidencia alta | No sustituir palabras simples por equivalentes académicos sin necesidad conceptual. |
| Rechazar solemnidad, grandilocuencia y falsa profundidad | Evidencia alta | Recortar cierres morales, abstracciones infladas y metáforas ornamentales. |
| Conservar dudas, contradicciones e irregularidades significativas | Evidencia alta | Distinguir tensión productiva de incoherencia accidental. |
| Admitir frases breves, tajantes y variaciones de ritmo | Evidencia alta | No normalizar longitud, cadencia o estructura de todos los párrafos. |
| Mantener primera persona y experiencia concreta | Evidencia alta | No convertir vivencias en afirmaciones impersonales o universales. |
| Mantener español rioplatense cuando aparezca naturalmente | Evidencia alta | Preservar voseo, léxico y giros existentes; no agregarlos de forma decorativa. |
| Tono crítico sin obligación de sonar académico | Evidencia alta | Exigir rigor en la idea, no una fachada institucional. |
| Conservar humor seco y observaciones incómodas | Evidencia alta | No explicar el chiste ni suavizar el conflicto por neutralidad. |
| Evitar conclusiones demasiado cerradas | Evidencia alta | No fabricar síntesis, moralejas ni llamados a reflexionar. |
| Preferir mostrar antes que explicar | Evidencia alta | Conservar escenas y detalles; recortar glosas que repiten lo visible. |
| Interés por las contradicciones mientras desarrolla una idea | Evidencia media | Permitir autocorrecciones y preguntas si hacen avanzar el pensamiento. |
| Pasar de una experiencia concreta a una reflexión | Evidencia media | Conservar el movimiento si nace del texto; no imponerlo como plantilla. |
| Mezclar experiencia personal, informática, filosofía y política | Evidencia media | Tolerar cruces de registro con función clara; marcar saltos sin puente conceptual. |
| Usar ironía ocasional | Hipótesis | Confirmar por contexto; no inventar ironías ni leer como irónico lo ambiguo. |
| Preferir cierta aspereza a una formulación diplomática | Evidencia media | No borrar fricción; corregir solo si impide comprender la postura. |
| Cuestionar ideas en el mismo acto de formularlas | Hipótesis | Preservar si aparece de manera sostenida; no insertar dudas artificiales. |

## Jerarquía para decidir

Ante un conflicto, priorizar:

1. intención comprobable en el texto actual;
2. patrones repetidos dentro del mismo texto;
3. preferencias de evidencia alta de este perfil;
4. evidencia media;
5. hipótesis.

No conservar un error objetivo solo porque se parece a una preferencia. No imitar mecánicamente la voz ni forzar todos los rasgos en cada pasaje.

## Señales de voz que conviene proteger

- detalle concreto que carga con la reflexión sin explicarla;
- primera persona que asume límites (“yo lo vi así”, “no estoy seguro”);
- frase corta que corta una explicación o cambia el ritmo;
- repetición con efecto retórico identificable;
- contradicción reconocida que complica honestamente la tesis;
- giro rioplatense ya presente y coherente con el registro;
- ironía que depende de no ser explicada;
- final abierto que deja una tensión real.

## Señales que requieren cautela

No declarar “voz del autor” basándose en una sola rareza. Comparar con el resto del texto y preguntar:

- ¿la irregularidad produce un efecto reconocible?
- ¿la repetición cambia el sentido o es accidental?
- ¿el salto puede seguirse aunque sea brusco?
- ¿la ambigüedad abre una lectura o confunde el referente?
- ¿el registro pertenece al narrador o parece pegado desde afuera?

Si la evidencia no alcanza, clasificar como `decisión estilística` y explicar la incertidumbre.
